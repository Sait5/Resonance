# Resonance — музыкальные инструменты в интерактивном 3D

**[Открыть сайт на Vercel](https://resonance-eta-lemon.vercel.app)** · **[Публичный репозиторий](https://github.com/Sait5/Resonance)** · [Скриншоты инструментов](artifacts/screenshots)

Resonance — веб-приложение, в котором можно исследовать музыкальные инструменты, играть на их 3D-моделях, менять настройки звука и разбирать короткие музыкальные фразы. Мышь, сенсорный экран, компьютерная клавиатура и MIDI-контроллер используют общий звуковой движок.

В проекте доступны восемь инструментов: рояль, акустическая гитара, электрогитара, бас-гитара, барабанная установка, скрипка, альт-саксофон и труба. Интерфейс поддерживает русский и английский языки.

## Что умеет приложение

- **Игра на 3D-модели.** Клавиши, струны, мембраны, тарелки и клапаны связаны с нотами и визуально реагируют на нажатие. Модели можно вращать на 360° по горизонтали и приближать колесом мыши.
- **Полифония.** Одна буква или цифра запускает одну ноту. Несколько одновременно удерживаемых клавиш позволяют играть созвучия. Отпускание одного источника ввода не обрывает ноту, удерживаемую другим.
- **Звук из записанных семплов.** Для инструментов используются аудиозаписи, а не один универсальный синтезатор. Семплы загружаются для выбранного инструмента; интерфейс показывает прогресс и ошибку загрузки.
- **Настройка звучания.** Громкость, теплота тембра, камертон A4 и транспозиция. Для барабанов доступны громкость и тембр. У гитар, баса и скрипки есть готовые строи и настройка отдельных струн.
- **Режим Watch.** Четыре оригинальные композиции Resonance имеют отдельные аранжировки для инструментов, визуализацию нот, паузу и изменение скорости.
- **Обучение.** Короткую фразу можно прослушать, затем повторить; приложение проверяет порядок нот.
- **Студия записи.** Запись с микрофона, отображение волны, прослушивание, обработка громкости, высоты, реверберации и задержки, скачивание записи.
- **MIDI.** Поддерживаются Note On, Note Off, сила нажатия, педаль сустейна рояля и команды остановки нот в пределах доступного диапазона инструмента.

## Архитектура

### Границы клиентской и серверной частей

Основная логика Resonance выполняется в браузере: 3D-сцена, ввод, воспроизведение, уроки и запись микрофона. Next.js подготавливает оболочку страницы и обслуживает приложение на Vercel. Интерактивная часть находится в клиентских компонентах.

У приложения сейчас нет отдельного API-сервера, базы данных, аккаунтов пользователей или серверного хранения записей. Эти компоненты не нужны для текущего сценария игры на инструменте. Настройки сохраняются в `localStorage` отдельно для каждого инструмента, а запись микрофона существует в браузере и может быть скачана пользователем.

### Общий путь события

```text
Мышь / касание / компьютерная клавиатура / MIDI / Watch
                         ↓
                  InstrumentEngine
                         ↓
      Нота + токен источника + сила нажатия
                         ↓
       Семпл → голос → огибающая → тембр → громкость
                         ↓
              Общий компрессор → аудиовыход

Состояние активных нот → индикация интерфейса и анимация 3D-деталей
```

### Звуковой движок

`lib/instrument-engine.ts` содержит общую реализацию воспроизведения. Один `AudioContext` используется для аудиосистемы приложения, а выбранный инструмент получает собственный экземпляр движка с набором декодированных семплов.

Каждое нажатие имеет свой **токен источника**: например, клавиатура, указатель или MIDI-порт. Это решает важную проблему полифонии: два источника могут удерживать одинаковую ноту, но отпускание одного не должно выключать другой. Повторное событие для уже удерживаемого токена не создаёт лишний голос.

При запуске ноты движок выбирает подходящий семпл. Для мелодических инструментов используется ближайшая записанная высота с изменением скорости воспроизведения; барабанные звуки выбираются по точному MIDI-номеру. Изменения строя, камертона и транспозиции применяются через `detune`. Тембр регулируется низкочастотным полочным фильтром, громкость — отдельным узлом усиления инструмента. Общий компрессор ограничивает пики при одновременном звучании нескольких голосов.

Движок учитывает отменённые нажатия во время загрузки, педаль сустейна рояля и естественный хвост ударных. Закрытый хай-хэт глушит открытый. При потере фокуса или скрытии страницы удерживаемые ноты отпускаются; при смене инструмента освобождаются обработчики, таймеры и аудиоресурсы.

### 3D-сцена и взаимодействие

`components/instrument-stage.tsx` загружает подготовленные GLB и связывает именованные детали с движком. Анимация выполняется в цикле кадра через ссылки на объекты Three.js, без обновления React-состояния на каждом кадре.

Клавиши поворачиваются относительно подготовленных точек вращения, клапаны смещаются, струны деформируются, а ударные поверхности и тарелки реагируют на удар. У скрипки есть отдельная модель смычка.

Тонкие струны трудно нажимать обычным пересечением луча и треугольников. `lib/string-raycast.ts` использует проекцию существующей струны на экран и допуск в пять пикселей. Для этого не создаются дополнительные невидимые 3D-кнопки. На время игры через указатель вращение камеры блокируется, чтобы нажатие и поворот сцены не конфликтовали.

### Композиции и обучение

`lib/performance.ts` формирует аранжировки из музыкальных событий: время, длительность, набор нот и сила нажатия. Для рояля предусмотрены мелодия и аккорды, для гитар — версии с открытыми струнами, для барабанов — ритмические партии. Режим Watch использует эти же события для звука и визуализации.

Композиции «Световые годы», «Орбитальный этюд», «Лунные арпеджио» и «Ночная серенада» — оригинальные учебные материалы Resonance; они не заявляются как точные транскрипции известных произведений.

## Управление

Актуальные буквы, цифры и ноты показаны под каждой 3D-сценой. Буквенные клавиши определяются по физическому коду клавиши, поэтому основные игровые привязки не зависят от выбранной раскладки.

| Инструмент | Цифровые клавиши | Особенности |
| --- | --- | --- |
| Рояль | 1–9, 0 | Дополнительные ноты верхнего регистра; буквы покрывают два других регистра |
| Акустическая гитара | 1–6 | Шесть открытых струн |
| Электрогитара | 1–6 | Шесть открытых струн |
| Бас-гитара | 1–4 | Четыре открытые струны |
| Барабаны | 1–9 | Бочка, малый барабан, закрытый и открытый хай-хэт, три тома, crash и ride |
| Скрипка | 1–4 | Четыре открытые струны |
| Альт-саксофон | 1–8 | Ноты в концертном строе |
| Труба | 1–9, 0, −, = | Двенадцать нот; поддерживаются соответствующие клавиши цифрового блока |

Для созвучия удерживайте несколько клавиш одновременно. На рояле **Shift + клик** закрепляет отдельную клавишу; повторный Shift + клик отпускает её. **Esc** отпускает удерживаемые ноты. На 3D-модели трубы клапаны можно комбинировать; Shift + клик закрепляет клапан.

## Настройки звука и строя

Настройки слышны при воспроизведении и сохраняются для выбранного инструмента в этом браузере.

- **Громкость:** 0–100%.
- **Теплота тембра:** −12…+12 dB; изменяет низкочастотную составляющую звука.
- **Камертон A4:** 415–466 Hz, стандартное значение — 440 Hz.
- **Транспозиция:** −12…+12 полутонов.
- **Отдельная струна:** смещение относительно стандартного строя на −12…+12 полутонов.

Готовые строи: стандартный, Drop D, Open G и DADGAD для акустической гитары; стандартный, Drop D и Drop C для электрогитары; стандартный, Drop D и понижение на полтона для баса; стандартный G D A E и скордатура A E A E для скрипки. Кнопка «Сбросить» возвращает исходные значения выбранного инструмента.

## Запуск локально

Нужен Node.js версии 22.13 или новее и npm. Команды выполняются из корня проекта.

```sh
git clone https://github.com/Sait5/Resonance.git
cd Resonance
npm ci
npm run dev
```

Локальный интерфейс доступен по адресу `http://localhost:5173`.

Для запуска именно production-сборки, используемой на Vercel:

```sh
npx next build
npx next start
```

После запуска `next start` откройте `http://localhost:3000`.

Команда `npm run build` сохраняет существующий путь сборки Vinext для Sites. На Vercel используется команда **`next build`**, явно заданная в `vercel.json`; эти два пути сборки не следует путать.

## Проверка проекта

```sh
node scripts/test-instrument-engine.mjs
npx tsc --noEmit
npx next build
```

Автоматическая проверка покрывает доступные ноты инструментов, целостность файлов семплов, полифонию и владение нотами, отмену нажатия до загрузки, MIDI-события, громкость, тембр и настройку высоты, двенадцать клавиш трубы, допустимость нот аранжировок, очистку ресурсов и наличие игровых деталей после экспорта GLB.

Тест звукового движка использует имитацию Web Audio API. Он проверяет маршрутизацию и параметры, но не заменяет прослушивание реального звука. В браузере дополнительно проверяются загрузка модели, игровые нажатия, совместное удержание нот, настройки, мобильная вёрстка и ошибки консоли. Подключение физического MIDI-контроллера требует отдельной проверки на устройстве.

## Подготовка моделей и аудио

Готовые модели и семплы уже включены в репозиторий — для обычного запуска Blender и повторная загрузка аудио не нужны.

Для воспроизведения подготовки моделей установите Blender 5.2 и выполните из корня проекта:

```sh
blender --background --python scripts/audit-models.py
blender --background --python scripts/prepare-instruments.py
```

Первый скрипт анализирует исходные модели и разделяет детали. Второй подготавливает геометрию, имена игровых объектов и экспортирует GLB, затем проверяет их повторным импортом. В `scripts/instrument-modeling.py` находятся функции процедурного моделирования. Редактируемые сцены и результаты проверки сохраняются в `artifacts/prepared/`.

Для повторного получения семплов:

```sh
node scripts/fetch-instrument-samples.mjs
```

Скрипт формирует манифест файлов; обработка записей альт-саксофона вынесена в `scripts/fetch-iowa-sax.mjs`. Загрузка требует доступа к внешним источникам.

## Развёртывание на Vercel

Текущий production-сайт: **https://resonance-eta-lemon.vercel.app**.

Проект Vercel связан с публичным репозиторием `Sait5/Resonance` и веткой `main`. Конфигурация находится в `vercel.json`:

- фреймворк — Next.js;
- установка зависимостей — `npm ci`;
- сборка — `next build`;
- каталог результата — `.next`.

Для развёртывания своей копии импортируйте репозиторий в Vercel, выберите корневую директорию `./` и используйте настройки из `vercel.json`. Для текущей функциональности приложения секреты и переменные окружения не требуются.

## Технические ограничения

Resonance — интерактивное музыкальное приложение, а не полноценная DAW или физическая модель акустики инструмента. У гитар и скрипки текущий игровой диапазон представлен открытыми струнами; свободное зажатие ладов и непрерывное управление положением смычка не реализованы. Набор доступных нот саксофона и трубы также ограничен подготовленным диапазоном.

Записанные семплы имеют конечную длительность. Изменение их высоты влияет на звучание и не воспроизводит все особенности реального инструмента. Планирование Watch работает по таймеру браузера и не заявляется как сэмпл-точная синхронизация профессионального аудиосеквенсора.

Звук может требовать первого действия пользователя из-за правил браузера. Микрофон требует разрешения и защищённого контекста; Web MIDI зависит от поддержки браузера и доступного оборудования. Настройки хранятся локально, без синхронизации между устройствами.
